First public version. Windows 10 or 11, 64-bit only.

**Install:** download the installer below (`Mango.Animation_0.1.0_x64-setup.exe`) and run it. It installs for your user only, no administrator needed. At first start the app checks your computer, lets you choose the features you want, and downloads only what they need, each item from its own source with its licence.

**What you need**
- Claude Code installed and signed in with your Claude account: Mango Animation does not ship it, it uses yours. If it is missing, the app tells you how to install it.
- An NVIDIA graphics card makes transcription and the silhouette much faster; without one they run on the processor.

**What to expect**
- The installer is not signed with a code-signing certificate: Windows SmartScreen may ask you to confirm ("More info" → "Run anyway").
- Updates are automatic, with your yes: at start the app checks for a new version and asks before installing it.
- "Precise cuts on words" uses the MMS model, licensed for non-commercial use only: if you earn from your videos, turn it off at first start or later on the Engines page.

The guide is in `docs/guida/` (English and Italian). Please report problems in the Issues, with what you did and what happened.
